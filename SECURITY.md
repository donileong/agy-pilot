## Reporting a Vulnerability

Security of user credentials (including Telegram Bot Tokens, system permissions, and local IPC sessions) is a top priority.

If you discover a security vulnerability in Antigravity Pilot:

1. **Do not create a public issue.**
2. Send an email to **`doni.leong@gmail.com`** with:
   - A description of the issue and potential impact
   - Step-by-step instructions or proof-of-concept to reproduce the vulnerability
   - Any suggested mitigations or patches
3. You will receive an acknowledgment within 48 hours.
4. We will coordinate a fix and release a patched version before public disclosure.

Thank you for helping keep Antigravity Pilot and its users safe!
